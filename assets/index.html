内置规则

自定义敏感词

命中后替换为 {{分组_xxxxxx}}；原文本就在 config.json 里， 因此占位符跨重启稳定。以 re: 开头的词按正则处理。

密钥前缀规则

前缀 + 至少 8 位字符，如 sk-

事件日志

左选事件、右侧看详情。详情里「原文」是客户端发出的内容，「发给上游」是脱敏后 实际转发给上游的内容（含 {{占位符}}）。凭据类受 mask.log_credential_plaintext 控制。

审计事件

被动检测：错误泄露 / 换芯 / 工具重写 / 流异常 / 响应投毒 / 跨请求污染 / 凭据回流 / 危险命令。

脱敏测试

与生产网关走同一套脱敏引擎。本测试使用独立的临时映射表， 运行结束即销毁 —— 不写入数据库，也不进入内存映射，不会影响线上占位符的稳定性。
示例： Ctrl / ⌘ + Enter 直接运行
